# codec

一个只依赖 Python 标准库的二进制帧编解码内核。它不监听端口、不读写文件，
只在内存里把字节编成帧、把帧解回字节：帧头带四位版本位与四位消息类型，
载荷长度是 varint 前缀，帧尾是 CRC32 校验。

- 帧格式：1 字节头（高 4 位版本、低 4 位消息类型）+ varint 长度 + 载荷 + 4 字节校验
- 整数载荷：zigzag varint
- 解析方式：单帧解码、整缓冲区多帧解码、可增量的流式解析器
- 错误情形：版本不符、长度超限、截断、校验和不匹配

## 目录

- codec/core.py：编解码、校验与解析器
- tests/test_core.py：行为测试

## 跑测试

在项目根目录执行：

    python3 -m unittest discover -s tests -v
